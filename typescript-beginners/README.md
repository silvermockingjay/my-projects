# My TypeScript Journey

## Course 'Beginner's TypeScript'
I've successfully finished Beginner's TypeScript Tutorial, which includes 18 lessons with tasks.  
This course has challenged me a bit and I would like to share my thoughts on it below

![The 'Beginner's TypeScript' course certificate ](https://res.cloudinary.com/total-typescript/image/upload/v1741523357/certificate/7ad06d3c-b94e-410a-a14a-f621e639b7a6/beginners-typescript.png)

### Advantages of this course:
 * Learning right from TypeScript documentation
 * Each topic has a practice task and a solution with video explanation
 * A student is provided with practical advices on what approach is expected at actual development process 
 * Lessons are short and useful
 * A student can run tasks right in a browser, no need to run exercises locally
 * The course is free of charge
 * In case of successful completion a student gets a certificate

### Disadvantages of this course:
 * Chaotic structure of the course
 * If a student isn't used to reading documentation and has no TS foundation, it might be difficult to follow the course
 * No explanation how a student can use the platform

## Course 'Learn TypeScript step by step in an interactive environment'
I've really enjoyed learning this course and would suggest to start from this one, if I have to choose among the two courses.  
Below you can see my thoughts on it.  

![The 'Learn TypeScript step by step in an interactive environment' course progress](<course.jpg>)

### Advantages of this course:
 * This course is beginner friendly
 * The structure is very well organized
 * The level of complexity is growing gradually
 * Each task has a small theory block and a practice task
 * Built-in code editor with task check
 * After each chapter a student get a flash-card, that they can use for a short knowledge refresh
 * A student has a course roadmap 
 * There's an opportunity to make notes and store it right on a platform

### Disadvantages of this course:
 * It's a paid course

## My reflections on what I've learnt
TypeScript is a powerful tool that has different benefits, such as: preventing a wide range of bugs, improving editor autocomplete experience and team work on code.  
I've started my TS journey from the second course and that was a very fortunate decision, as it gave me a good basic knowledge and understanding why I as a developer need to use TypeScript, on which I could build up in the 'Beginner's TypeScript' course.  
I liked that the first tutorial makes you read documentation, to search on your own for the information you need to solve a code task, because that's what you have to do on a daily basis as a developer. The tasks in this course are of a middle complexity and challenge you to think and learn hands on.
